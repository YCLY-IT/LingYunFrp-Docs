# 客户端启动隧道

## 1. 下载客户端

- 从[客户端下载](https://www.lyfrp.cn)下载客户端
- 根据自己的操作系统选择合适的客户端下载
- 下载完成后，运行客户端

## 2. 创建隧道（以windows为例）

- 登录您的 LingYunFrp 账号

![登录](../../public/image/cl1.png)

- 点击「隧道管理」

![创建隧道](../../public/image/cl2.png)

- 点击「创建隧道」

![隧道列表](../../public/image/cl3.png)

- 选择合适节点并点击「下一步」

![创建隧道](../../public/image/cl4.png)

- 填写隧道信息并创建新隧道

![创建隧道](../../public/image/cl5.png)

## 3. 启动隧道

- 单击如图所示按钮

![启动隧道](../../public/image/cl6.png)

- 稍等片刻即启动成功
