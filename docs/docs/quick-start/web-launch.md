# 网页启动隧道

在网页端创建并启动隧道，最后仍需本机连接 frpc 才能真正打通。

## 1. 登录

- 在浏览器中输入 `https://www.lyfrp.cn`
- 点击「立即登录」

![登录1](../../public/image/pc1.png)

- 填写您的相关信息并登录您的 LingYunFrp 账号

![登录2](../../public/image/pc7.png)

## 2. 创建隧道

- 在主界面中打开隧道列表

![主界面](../../public/image/pc6.png)

- 根据需求选择合适节点并点击该节点

![隧道列表](../../public/image/pc5.png)

- 填写隧道信息

![创建隧道](../../public/image/pc3.png)

## 3. 启动隧道

- 依次点击「隧道列表」「配置」「启动隧道」

![启动隧道](../../public/image/pc8.png)

- 确保隧道已在线

![隧道状态](../../public/image/pc2.png)

::: warning 注意
在网页端启动隧道并不意味着在客户端启动隧道。如果要打通隧道，需要在对应的服务器或电脑上下载客户端或 frpc 启动才行。
:::
