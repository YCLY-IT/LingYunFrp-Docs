# 了解指南

你在内网跑着一个服务，外网访问不到。frp 做的事就一件：把内网的 `本地IP:本地端口` 映射成公网上能访问的 `节点域名:远程端口`。

```
访问者  ──►  节点域名:远程端口  ──►  你机器上的 本地IP:本地端口
```

这条映射关系叫**隧道**。在面板上创建隧道，本机用 frpc（frp 客户端）连上节点，隧道就上线了，断开 frpc 就下线。

## 名词的含义

| 说法 | 含义 |
| --- | --- |
| 节点 | 一台有公网地址的服务器，隧道开在它上面。面板上就能看到名称和当前负载 |
| 隧道 | 一条映射规则：本地 `IP:端口` ↔ 节点上的一个远程端口 |
| Token | frpc 连接节点时用的凭证，16 位字母，用来表示隧道的所有权 |
| 用户组 | 决定能建多少条隧道、能用多少带宽、能用哪些节点 |
| 流量 | 上下行流量之和，单位 MB |
| 实名认证 | 部分节点要求完成实名后才能使用 |
| 签到 | 每天签到可领积分和流量 |

## 需要准备什么

- 一台能上网、跑着待暴露服务的机器
- frpc 客户端，版本尽量不要落后，否则可能连不上节点
